# Shared Research (sbc-research)

Мод для Mindustry, который позволяет игрокам-клиентам изучать древо технологий в кооперативной кампании через хоста.

## Возможности
- Клиенты могут исследовать технологии, а не только хост
- Хост ничего не подтверждает вручную: скрипт мода сам проверяет запрос, списывает ресурсы и открывает технологию
- Работает с другими модами: их технологии тоже можно изучать

## Требования
- Mindustry 160.7
- Кооперативная кампания (мультиплеер)
- **Мод должен быть установлен и у хоста, и у всех клиентов**

## Установка

**Через игру:**
1. Моды → Импорт с GitHub
2. Введи `darkblackcat-dotcom/sbc-search-research`

**Вручную:**
1. Скачай `.zip` из раздела [Releases](../../releases)
2. Моды → Импорт мода → выбери файл

После установки перезапусти игру.

## Как пользоваться
1. Хост создаёт кооперативную игру в кампании
2. Клиенты подключаются (мод у всех уже установлен)
3. Клиент открывает древо технологий и изучает нужную технологию
4. Мод автоматически обрабатывает запрос на хосте: ресурсы списываются, технология открывается

## Известные проблемы
- Если мод стоит не у всех игроков, исследования работать не будут
- Сообщай о других проблемах в [Issues](../../issues)
